# 🤖 دليل نظام أتمتة الأخبار والترندات الذكي — راقمنا 2026

> نظام آلي متكامل يراقب 267 موقعاً وهيئة حكومية جزائرية + كبرى الصحف الجزائرية + ترندات قوقل الحية في الجزائر، ويقوم بالتحقق من المصادر وكتابة مقالات سيو احترافية حصرية وفهرستها فورياً في محركات البحث.

## 🏗 هيكل النظام المعماري

```
scripts/news-automation/
```

## ⏱ الجدولة الذكية وتوفير الموارد (Smart Scheduling)

لحماية حصص GitHub Actions و Gemini API من الاستنزاف، تم ضبط المواعيد بدقة:

| المهمة | التكرار | التوقيت (بتوقيت الجزائر) | الوصف |
|---|---|---|---|
| **الأخبار الحكومية الرسمية** | كل ساعة (`0 * * * *`) | على مدار الساعة | فحص أهم 10 مواقع وهيئات حكومية |
| **رادار الترندات والإعلام الجزائري** | كل 3 ساعات (`0 8,11,14,17,20,23 * * *`) | من 9:00 ص إلى 12:00 ليلاً | صيد كلمات البحث الرائجة ومطابقتها مع المصادر الرسمية |
| **المواقع الحكومية الثانوية** | مرة واحدة يومياً (`0 2 * * *`) | الساعة 3:00 فجراً | فحص باقي المواقع الـ 257 |

## 🛡 القواعد الصارمة لمنع المحتوى الرديء والتزييف

1. **فلتر التخصص الذكي (Niche Filter)**:
   - ❌ **يستبعد فوراً:** الرياضة، كرة القدم، أخبار المشاهير، والسياسة الدولية.
   - ✅ **يقتنص فوراً:** (التربية والتعليم، مسابقات التوظيف، منحة البطالة، سكنات عدل، البريد والبطاقة الذهبية، بطاقة الشفاء، الوثائق الإدارية، الضرائب، وفواتير سونلغاز).

2. **قاعدة التحقق من المصدر (المصداقية 100%)**:
   - يتم مطابقة أي ترند مع قاعدة البيانات الرسمية (267 جهة جزائرية).
   - **إذا لم يثبت ارتباط الترند بمصدر رسمي أو بيان موثوق، يتجاهله السكريبت تماماً ويكتب 0 مقالات.**

3. **قاعدة الصور الصارمة (Zero-Hallucination)**:
   - يتم استخراج `og:image` الحقيقية حصراً عبر Node.js (`cheerio` + `axios`).
   - في حال عدم وجود صورة في البيان، يتم وضع الصورة الافتراضية التوضيحية `/images/default-placeholder.png`.
   - **ممنوع منعاً باتاً لـ Gemini كتابة أو تخيل أي وسوم صور أو روابط وهمية.**

```text

1. عنوان رئيسي جذاب (H1)، مقدمة قوية، عناوين فرعية (H2, H3)، فقرات قصيرة، قوائم نقطية، خاتمة ودعوة لاتخاذ إجراء (CTA).
2. إذا لم يذكر البيان الرسمي أرقاماً معينة، اكتب حرفياً: 'لم يُكشف بعد عن الأرقام الرسمية'. ممنوع منعاً باتاً اختراع أو تخمين أرقام أو تواريخ.
3. اقتبس حرفياً الفقرة الرسمية الأولى من البيان مع وضع علامات تنصيص وذكر المصدر والجهة.
4. في نهاية المقال، أنشئ قسماً بعنوان "الأسئلة الشائعة" يضم 3 أسئلة وأجوبة تخص الموضوع.
5. ممنوع منعاً باتاً كتابة أي كود HTML للصور أو إضافة روابط صور، لأن السكريبت الخارجي يتكفل بالصور. أنت تكتب النص فقط.
6. يجب أن يكون اللغة عربية فصيحة، مع مراعاة المصطلحات المتداولة في الجزائر."
```

## ➕ كيفية إضافة مصدر إخباري جزائري جديد

افتح ملف `scripts/news-automation/sites-config.json` وأضف مصدراً جديداً داخل مصفوفة `algerian_news_sources`:

```json
{
  "id": "elkhabar",
  "name": "الخبر الجزائرية",
  "url": "https://www.elkhabar.com",
  "rssUrl": "https://www.elkhabar.com/rss",
  "category": "general_news"
}
```

## 🔐 إعداد المفاتيح السرية في GitHub (GitHub Secrets)

اذهب إلى مستودعك: **Settings ⬅ Secrets and variables ⬅ Actions ⬅ New repository secret**:

1. **`GEMINI_API_KEY`**: مفتاح Gemini API من [Google AI Studio](https://aistudio.google.com).
2. **`GOOGLE_SERVICE_ACCOUNT_KEY`**: محتوى ملف `service-account.json` الخاص بـ Google Search Console.

## 💻 أوامر التشغيل المحلي (CLI)

```bash
# تشغيل رادار الترندات والإعلام الجزائري
npm run news:trends

# تشغيل فحص الأخبار الحكومية الرسمية (Tier 1)
npm run news

# تشغيل فحص المواقع الحكومية الثانوية (Tier 2)
npm run news:tier2

# تشغيل فحص كافة المواقع الـ 267
npm run news:all

# تشغيل محرك الفهرسة وتوليد الـ Sitemap
npm run news:index
```

## ❓ الأسئلة الشائعة (FAQ)

**س: كيف يضمن النظام عدم تكرار نفس المقال؟**
ج: يسجل النظام كل الروابط وعناوين الترندات في ملف `history.json` تلقائياً فور معالجتها، ويتخطاها في كل الدورات القادمة.

**س: ماذا لو لم يظهر أي ترند رسمي يخص الجزائر؟**
ج: يتوقف السكريبت فوراً بعد الفحص الأولي ويكتب 0 مقالات بدون استهلاك توكنز من Gemini.

**س: هل الصور المرفقة قانونية وآمنة؟**
ج: نعم، يتم سحب وسم `og:image` الرسمي المعتمد من أصحاب المواقع أنفسهم، دون تعديل أو تخمين.
